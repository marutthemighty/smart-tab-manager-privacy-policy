Privacy Policy

Last updated: May 19, 2026

Smart Tab Manager + Session Saver is built with privacy as a core principle.

1. Data Collection

This extension does not collect any personal data.

  • All sessions, tabs, and settings are stored locally on your device using Chrome's local storage.
  • No analytics, tracking, or telemetry is implemented.

2. Permissions Used

  • tabs: Used only to read open tabs when saving a session and to create tabs when restoring sessions.
  • storage: Used to persistently save your sessions and preferences locally.
  • alarms: Used to wake up snoozed tabs at the scheduled time.
  • idle: Used (optionally) to detect idle state for auto-closing inactive tabs.
  • notifications: Used to show non-intrusive success messages.

3. Third Parties

The only external service used is Gumroad for optional Pro license verification. This happens only when you manually enter a license key. No other data is sent.

4. Data Sharing

We do not share, sell, or transmit any user data to any third party.

5. Your Rights

You can:

  • Export all your sessions as JSON anytime
  • Clear all data instantly from the Settings menu
