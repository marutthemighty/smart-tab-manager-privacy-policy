Privacy Policy

Last updated: May 19, 2026

1. Overview

Smart Tab Manager + Session Saver is a local-first Chrome extension that helps you save, organize, restore, and manage browser sessions.

We take your privacy very seriously. This extension is designed to work completely offline.

2. Data Collection

This extension does not collect, store, or transmit any personal data to any external server.

  • All saved sessions, tab data, and settings are stored locally on your device using Chrome’s local storage API.
  • No analytics, tracking, or telemetry is implemented.

3. Permissions & Their Use

  • tabs: Used only to read open tabs when saving a session and to open tabs when restoring a session.
  • storage: Used to persistently save your sessions and preferences locally.
  • alarms: Used to wake up snoozed tabs at the scheduled time.
  • idle: Used (optionally) to detect user idle state for auto-closing inactive tabs.
  • notifications: Used to show non-intrusive success messages (e.g., after keyboard shortcut save).

4. Gumroad License Verification (Pro)

When you choose to unlock Pro features, the extension makes a one-time network request to Gumroad’s official API to verify your license key. No other data is sent.

5. Data Sharing

We do not sell, share, or disclose any user data to any third parties.

6. Your Rights

You can:

  • Export all your sessions as JSON at any time
  • Clear all data instantly via Settings → Clear All Sessions
