# Privacy Policy for Smart Tab Manager + Session Saver

**Last updated:** May 19, 2026

This Chrome extension ("Smart Tab Manager + Session Saver") is built with privacy as a core principle.

## Data Collection
- This extension **does not collect** any personal data.
- All sessions, tabs, and settings are stored **locally** on your device using Chrome's local storage.
- No data is sent to any external server except for the optional one-time Gumroad license verification when you choose to unlock Pro features.

## Permissions Used
- **tabs**: Used only to read and create tabs for saving/restoring sessions.
- **storage**: Used to save your sessions and settings locally.
- **alarms, idle, notifications**: Used for snooze functionality and background maintenance.

## Third Parties
The only external service used is **Gumroad** (for optional Pro license verification). This happens only when you manually enter a license key.

## Data Sharing
We do not share, sell, or transmit any user data to any third party.

## Your Rights
You can export all your sessions as JSON at any time. You can also clear all data through the Settings menu.
